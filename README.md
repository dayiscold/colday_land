# Artist Website

## Описание

Cайт артиста и звукорежиссера. Сайт предоставляет пользователям доступ к последним релизам артиста и фирменному мерчу.

Проект разработан с использованием **FastAPI** для обеспечения высокой производительности и удобства API-интеграции.

## Функционал

- Загрузка и отображение релизов COLDAY
- Управление каталогом фирменного мерча
- API для получения информации о релизах и товарах
- Административный интерфейс для управления контентом

### Установка зависимостей

```bash
pip install -r requirements.txt --upgrade pip
```
